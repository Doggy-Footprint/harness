- `run(instances, arms, *, cfg, harness_ref="HEAD", model=None, effort=None, cap_min=None, docker=<docker_exec module>, now=time.time) -> Path` — `instances` are pool row dicts; raises `TokenFileMissing` (a `RuntimeError` whose message is `token file missing: <path>`) before any docker call; new run id (16 lowercase hex), run directory `<runs_dir>/<run_id>` (mode 0700, parents created 0700), entries in order instance-major then arm order; returns the run directory.
- `resume(run_id, *, cfg, docker=…) -> Path` — continues entries whose host state is `interrupted` or absent; leaves other entries untouched; reuses the original run's effective `model`, `effort`, `wall_clock_min`, `harness_ref`, `harness_commit` and `selfcheck_commit`, stored at run start in `<run_dir>/params.json`, and takes everything else from `cfg`; raises `TokenFileMissing` as above and `UnknownRunError` (a `LookupError`) when `<runs_dir>/<run_id>/run.json` or `params.json` is absent, before any docker call. An interrupted entry resumes with `start_commit` and `install` from its `manifest.json`; without one, `start_commit` comes from the start-commit command. Instance rows are reloaded from `fixtures/instances.jsonl` by id.
- Per entry directory `<run_dir>/<instance_id>/<arm>/`: `manifest.json`, `state.json` (driver state plus host fields `container`, `host_timeout`, `scrubbed_occurrences`, `error`), `prediction.json` (non-interrupted terminal states only), `raw/` (copy of the container's `out_dir`, `full.diff`, `install.log`). `<run_dir>/run.json` = `{"run_id", "entries": [{"instance_id", "arm", "status"}], "created_at"}` rewritten after each entry; `<run_dir>/predictions.<arm>.jsonl` = one line per finished entry of that arm, equal to that entry's `prediction.json` after scrubbing.
- Host state field `error` = the host-detected failure reason (the same string as `reason`) or null; a driver-reported `error` keeps it null. `run.json` `created_at` = the `now()` value. `prediction.json` exists only when the driver ended in a state other than `interrupted` and extraction succeeded; host-detected failures (`image missing`, `container lost`, `install failed`, `driver exit`, `driver state missing`, `git failed`) write none; a host timeout keeps `reason: wall_clock`. Manifest `container.user` is `"nonroot"`; `install.hooks_path` is null when unset. In `image missing: <name>`, `<name>` is the derived image name when the tools and instance images exist, otherwise the absent tools or instance image name. `images --agent` prints lines for derived images only.
- Host `reason` values: `image missing: <name>; run python -m selfcheck images --agent`, `container lost`, `install failed: exit <n>`, `driver exit <n>` (any non-zero driver exit), `driver state missing` (exit 0 without a readable `state.json`), `git failed: <output>`, `token remained after scrub`. Driver input fields set by the host: `token_path` `/run/secrets/oauth_token`, `out_dir` `/selfcheck/out`, `proxy_url` as above, `phrase` = `user_sim.PHRASE`, `wall_clock_s` = 60 × effective `wall_clock_min`.
- Agent container: `docker.start_container(<derived image>, name="selfcheck-agent-<run_id>-<n>", network=cfg.network, labels={"selfcheck.agent": run_id}, cpus=cfg.cpus, memory=cfg.memory, mounts=["type=bind,src=<expanded token_file>,dst=/run/secrets/oauth_token,readonly"])`, `<n>` = the 1-based position of the entry in `run.json` `entries`; no other mounts, no `-e` options; the driver, `input.json` and the harness source are copied in with `docker cp`; `/selfcheck/out` is created owned by `nonroot`.
- Harness arm install: `git archive <harness_commit> harness installer` extracted to `/opt/harness-src` in the container; as nonroot in `/testbed`: `printf 'y\ny\ny\n' | /opt/selfcheck-py/venv/bin/python /opt/harness-src/installer/harness.py install /testbed --no-ci`; replace the placeholder `[#TODO][3-5 lines of description of the project]` or `[#TODO]Alert user to set up definition & north-start of the project.` in `AGENTS.md` with `project_defs.json[repo]`; `git add -A && git -c core.hooksPath=/dev/null -c user.name=selfcheck -c user.email=selfcheck@localhost commit -q -m "selfcheck: install harness"`; `start_commit` = the new HEAD; record `git config --get core.hooksPath` and whether `.pre-commit-config.yaml` exists; remove `/opt/harness-src`. Baseline: `start_commit` = `git rev-parse HEAD`.
- Driver exec: `docker exec -u nonroot -w /testbed <c> /opt/selfcheck-py/venv/bin/python /opt/selfcheck/agent/driver.py /selfcheck/in/input.json` with timeout `wall_clock_s - elapsed_s + host_grace_s`.
- `scrub(directory, token) -> int` — `token` is `str` (UTF-8 encoded) or `bytes`; an empty token returns 0 and changes nothing; symlinks and other non-regular entries are skipped without stopping the walk; replaces every occurrence of the token bytes in every regular file below `directory` with `b"[REDACTED]"`, returns the number replaced.

docker_exec additions (existing functions keep their signatures and behaviour):
- `start_container(image, *, name, network, labels, cpus, memory, mounts) -> Container` (not removed automatically), `Container.exec(argv, *, timeout=None, user=None, workdir=None)`, `Container.stop()`, `Container.start()`, `container_exists(name) -> bool`, `network_exists(name)`, `ensure_network(name, internal=True)`.

CLI (`selfcheck/__main__.py`):
- `images --agent [--instances a,b]` — builds the tools image and the derived images (default: every pool instance); prints one line per image `<instance_id> <image>`; exit 1 when any build fails.
- `run [--instances a,b] [--arms harness,baseline] [--harness-ref REF] [--model ID] [--effort LEVEL] [--cap-min N]` — default instances: pool rows with `core` true; default arms `harness,baseline`; prints the run directory; exit 0 when every entry reached a terminal state (any status), 1 when an entry ended in `error`, 2 for usage errors.
- `run --resume RUN_ID` — exit codes as above; `UnknownRunError` → stderr `unknown run id: <RUN_ID>`, exit 2.
- The CLI calls `run.run`, `run.resume`, `images.build_tools_image` and `images.build_derived_image` through module attribute lookup with `cfg=CONFIG["agent"]`, so tests patch those attributes; exit 1 is decided from the returned run directory's `run.json` statuses; `TokenFileMissing` and `DockerError` print to stderr and exit 1. `images` without `--agent` keeps its M1 behaviour.

Generated files: `swe.build_images(instances, *, max_workers=2, workdir=None)` runs swebench's `build_instance_images` with the process working directory set to `workdir` (default `<expanded config.json cache_dir>/build`, created when absent) and restores the previous working directory afterwards, also when the build raises, so its `logs/` tree is written there; the Test command writes coverage data to `~/.harness/selfcheck/.coverage`.

# Errors
- Token file missing or not a regular file — stderr `token file missing: <path>`, exit 1 — no run directory entries started, no container.
- Derived image absent at run time — entry `error`, reason `image missing: <name>; run python -m selfcheck images --agent` — no container created; next entry continues.
- Image build fails — `ImageBuildError` naming the image with the log tail; `images --agent` exit 1 — other images still attempted; no partial tag.
- Proxy or network cannot be ensured — `run` exits 1 with the docker output — no agent container.
- Installer exits non-zero, or the install commit fails — entry `error`, `raw/install.log` holds the output — container removed.
- Driver input unreadable — driver exit 2 — host entry `error` reason `driver exit 2`.
- SDK/CLI raises during the loop — driver `status: error`, `reason` set, exit 0 — host extracts and removes the container.
- Rate limit — `interrupted` — container stopped and kept; `prediction.json` absent; `run` exit 0.
- Host exec timeout — `capped` with `host_timeout: true` — driver process killed by `freeze`; extraction proceeds.
- Seed restore fails — prediction `seed.ok: false` — extraction proceeds; entry status unchanged.
- Git add/diff fails — entry `error` with the git output — `raw/` collected, container removed.
- Token found after scrub — entry `error`, reason `token remained after scrub` — files kept for inspection with the count recorded, never the token.
- Resume of a run id without `run.json` — exit 2, `unknown run id` — nothing changed.
