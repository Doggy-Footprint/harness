# Signatures
Common types (JSON-serializable dicts):
- Instance row: keys `instance_id, repo, version, base_commit, environment_setup_commit, patch, test_patch, FAIL_TO_PASS (list[str]), PASS_TO_PASS (list[str]), problem_statement, difficulty, created_at`; `hints_text` is never stored.
- Status values: `"PASSED" | "FAILED" | "SKIPPED" | "ERROR" | "XFAIL"`. PASS set = {PASSED, XFAIL}; FAIL set = {FAILED, ERROR} plus absence from the status map; SKIPPED is neither.
- EvalResult: `{"key": str, "apply": "ok"|"src_failed"|"test_failed", "status": dict[str,str], "exit_code": int|None, "no_tests": bool, "timed_out": bool, "log_path": str|None}`.

selfcheck/swe.py (the only module importing swebench):
- `image_name(instance: dict) -> str` — `sweb.eval.arm64.<instance_id lowercased>:latest`.
- `make_spec(instance: dict, test_patch: str | None = None)` — swebench 4.1.0 `make_test_spec(row, namespace=None, arch="arm64")`, with `row["test_patch"]` replaced when `test_patch` is not None.
- `directives(instance: dict, test_patch: str | None = None) -> list[str]`.
- `eval_script(instance: dict, test_patch: str | None = None) -> str` — swebench script plus three markers: prints `SELFCHECK_TEST_APPLY_FAILED` and exits non-zero when the heredoc test-patch `git apply` fails; when `directives(...)` is empty prints `SELFCHECK_NO_TESTS` and exits 0 without running any test command; prints `SELFCHECK_EXIT=<n>` with the test command's exit status on the line after the test command (`echo SELFCHECK_EXIT=$?`); the apply-failure line is `[ $? -eq 0 ] || { echo SELFCHECK_TEST_APPLY_FAILED; exit 1; }` directly after the heredoc. All other lines equal swebench's script.
- `parse_status(instance: dict, log_text: str) -> dict[str, str]` — swebench repo parser applied to the text between the start/end test-output markers.
- `build_images(instances: list[dict], *, max_workers: int = 2) -> tuple[list[str], list[str]]` — (built or existing ids, failed ids).

selfcheck/docker_exec.py: container helpers; every container is started with label `selfcheck=1` and removed (`docker rm -f`) on every exit path. When a docker CLI call fails, it probes `docker info`; if the probe also fails, it re-probes every 2 s for up to `SELFCHECK_DOCKER_WAIT_S` seconds (default 60) and, once the daemon answers, retries the failed call once; if the daemon never answers, it raises `RuntimeError`. A failure while `docker info` succeeds is final (no retry), except an image lookup during engine start: when a call that names an image (`image inspect`, `run`) fails with "No such image" while `docker image ls -q <name>` lists that name, it re-checks every 2 s for up to `SELFCHECK_DOCKER_WAIT_S` seconds until `docker image inspect <name>` succeeds, then retries the call once; if the name never resolves it raises `RuntimeError`. A name that `docker image ls` does not list is missing at once (no wait).

selfcheck/evaluate.py:
- `evaluate(instance: dict, src_diff: str, test_patch: str, *, repeat: int = 0, timeout_s: int = 1800, cache_dir: str | Path | None = None, network: bool = False) -> dict` — EvalResult. Fresh container from `image_name(instance)` per call; network disabled unless `network=True`; non-empty `src_diff` applied with the swebench sequence (`git apply --verbose`, then `git apply --verbose --reject`, then `patch --batch --fuzz=5 -p1 -i`), all failing → `apply="src_failed"`, empty status, tests not run; then `eval_script(instance, test_patch)` runs; `SELFCHECK_TEST_APPLY_FAILED` → `apply="test_failed"`; `SELFCHECK_NO_TESTS` → `no_tests=True`; timeout → `timed_out=True`. Cache key = sha256 over image id, eval script text, src_diff, test_patch, repeat, network; with `cache_dir`, an existing entry is returned without starting a container. The image id comes from the daemon; when the daemon is unreachable, the last id recorded under `cache_dir` for that image is used.
- `read_files(instance: dict, src_diff: str, paths: list[str]) -> dict[str, str | None]` — file contents in `/testbed` after applying `src_diff` (None when absent); raises `RuntimeError` when `src_diff` does not apply.
- `compile_ok(instance: dict, patch: str, paths: list[str]) -> bool` — patch applies and the testbed interpreter `python -m py_compile` succeeds on every path.

selfcheck/patches.py:
- `load_rules(path: str | Path | None = None) -> dict` — default `selfcheck/fixtures/path_rules.json`.
- `classify_path(path: str, repo: str, *, is_new: bool = False, rules: dict | None = None) -> str` — `"excluded" | "scratch" | "test" | "src"`, precedence excluded > scratch > test > src.
- `file_sections(diff: str) -> list[dict]` — one per `diff --git` section: `{"path": b-path, "old_path": a-path, "is_new": bool, "is_deleted": bool, "text": section text}`. Input domain: `git diff` output for a repository (any `core.quotePath`, rename and copy detection on or off, with `a/`/`b/` prefixes; `git diff --no-index` output is outside it). `path`/`old_path` are plain repository paths: a C-style quoted name (`"a/…"` with git's backslash escapes `\a \b \t \n \v \f \r \" \\` and three-digit octal bytes, decoded as UTF-8; bytes that are not valid UTF-8 give a str that `os.fsencode` maps back to those bytes) in the `diff --git`, `---`, `+++`, `rename from`, `rename to`, `copy from`, `copy to` lines is unquoted; in a rename or copy section `old_path` is the source and `path` the destination, and a copy section is neither new nor deleted; the TAB git appends to a `---`/`+++` name containing a space is not part of the path. `is_new`/`is_deleted` are derived only from header lines (before the first `@@`); hunk body content never sets them.
- `split_patch(diff: str, repo: str, rules: dict | None = None) -> dict[str, str]` — keys `src, test, scratch, excluded`; each value is the byte-identical concatenation of that class's sections in input order, `""` when none.
- `changed_lines(diff: str) -> dict[str, list[int]]` — sorted post-image line numbers of `+` lines per b-path; every non-deleted section's b-path is a key (an empty list when it adds no lines, e.g. an empty new file or a mode-only change); deleted files omitted.
- `apply_to_texts(files: dict[str, str | None], patch: str) -> dict[str, str | None]` — applies `patch` to the given pre-image texts with `git apply` in a temporary repository and returns post-image texts for the same keys plus any file the patch creates (None = deleted/absent).

selfcheck/pool.py:

- `eligible(row: dict, *, swt_ids: set[str], difficulties: list[str], min_hunks: int, excluded_ids: set[str] = frozenset()) -> bool` — id in swt_ids, difficulty in difficulties, hunks ≥ min_hunks, id not in swebench `USE_X86`, id not in excluded_ids.

Independent of input row order.

# Errors
- Src diff does not apply — `apply="src_failed"`, empty status, no tests run — container removed, cache entry written.
- Test patch does not apply — `SELFCHECK_TEST_APPLY_FAILED`, `apply="test_failed"` — container removed.
- No test directives — `SELFCHECK_NO_TESTS`, `no_tests=True`, empty status — no suite run.
- Evaluation exceeds `timeout_s` — `timed_out=True` — container killed and removed.
- Docker image missing — evaluate raises `RuntimeError` naming the image — no container left.
- Docker daemon unreachable on a cache miss — `RuntimeError` after the readiness wait — no cache entry written.
- Docker daemon temporarily unavailable (e.g. Docker Desktop Resource Saver unpausing) — call retried after the daemon answers — normal result.
- Engine starting after Docker Desktop's idle shutdown: the daemon answers and `docker image ls` lists the image, but name lookups report "No such image" — lookup re-checked until it resolves, call retried once — normal result; never resolving within the wait — `RuntimeError` — no container left.
- Agent test patch does not apply to base in scoring — no exception; no agent tests, kill evaluation skipped — score returned.
- Mutant fails testbed compilation — `compile_ok=False` — excluded from denominators.
- Unparsable test file in attribution — `changed_tests` → None — every id of that file attributed.
- Validation failure — `valid=False` with reason codes — `pool` continues with the next ranked candidate.
- Fewer valid candidates than `size` — CLI exit 1 with message — fixtures written for the valid subset.
- Unknown CLI subcommand or bad flag — exit 2.
- `apply_to_texts` patch does not apply — `ValueError` — no files changed.
- `read_files` src diff does not apply — `RuntimeError` — no container left.
- `leak_check` cannot complete (script timeout, gold patch does not apply to the scratch copy, unparsable output) — `RuntimeError` whose message contains the instance id — `validate_instance` catches it and records reason `leak` with `leak = {"ok": false, "error": <message>}`; the pool continues.
